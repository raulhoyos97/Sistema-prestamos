# Sistema de Préstamos Personal

Sistema de gestión de préstamos desarrollado en Python.

## Funciones
- Registrar clientes
- Registrar préstamos con interés del 15%
- Calcular fecha de vencimiento automática
- Guardar y cargar datos en archivo JSON
- Ver préstamos vencidos

## Tecnologías
- Python 3
- JSON para almacenamiento de datos
